Bitcoin Core wallet check

Proves a wallet file opens in Bitcoin Core …. The file is imported by a real, unmodified bitcoind running in an Alpine Linux machine emulated in this tab, with no network device. Your file never leaves the browser, and the machine is gone when you close the tab.
