    Pick one or more machine profiles. A profile is a JSON file naming the images to boot (ISO, disk, kernel) and the machine to run them on. Images are loaded from this server unless the profile gives absolute urls.

    Fetch a profile from a url. Relative image paths in it are resolved against the profile's location.
